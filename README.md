# VYRO

A small learning chatbot made with HTML, CSS and JavaScript.

## Commands

### Teach VYRO
Use this command to teach VYRO a fact.

Format:
`Thing is a description`

Example:
`Earth is a planet`

VYRO will remember the information and use it when asked.

### Ask VYRO
Use this command to ask VYRO about something it knows.

Format:
`What is (thing)`

Example:
`What is Earth`

If VYRO has learned it, it will answer.

### Add Response
Use this command to make VYRO respond to a word or phrase.

Format:
`Respond to (word) (response)`

Example:
`Respond to hello Hello!`

For phrases with spaces, use quotes.

Example:
`Respond to "thank you" No problem!`

### Change Name
Use this command to change VYRO's name.

Format:
`Name (new name)`

Example:
`Name Clanker`

### Forget Memory
Use this command to remove something VYRO learned.

Format:
`Forget (thing)`

Example:
`Forget Earth`

### View Brain
Press the BRAIN button to see VYRO's saved memories and responses.

## Saving

VYRO saves its memory in your browser, so your learned information stays after closing the page.
